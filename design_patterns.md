# Design Patterns – Habit Tracker Team Tuple

## 1. Introduction

This document describes the software design patterns and design principles considered for the Habit Tracker application.

The application is developed using Python as part of the Python for Data Science group project at SRH Hochschule Heidelberg.

## 2. Application Architecture

The application follows a modular structure in which different Python files are responsible for specific functionalities.

- `main.py` – Application entry point and menu management.
- `utils.py` – Common utility functions.
- `storage.py` – Data storage and retrieval.
- `habits.py` – Habit creation and management.
- `analytics.py` – Habit statistics and streak calculations.
- `reports.py` – Reports and data visualization.
